# African & Global Currency & Scientific Utility Suite

## Target User
A cross-border trader, traveler, or student in West Africa who needs immediate multi-currency conversion alongside a scientific calculator.

## Problem Solved
Eliminates the friction of manually calculating exchange rates between Nigerian Naira, regional African zones, and global economies (USD, CNY, RUB) while juggling multiple separate utility tools.

## Three Checks That Prove It Works
1. **Live API Integration:** The app queries the exchange rate endpoint on load and displays a success message confirming rates are active.
2. **Dynamic Calculation:** Modifying the NGN input value instantly updates the converted output for any chosen regional or global currency.
3. **Scientific Computation:** Tapping operands and functional buttons correctly parses and calculates expressions on the digital display.

## Main Limitation
The currency conversion feature depends on an active internet connection to pull real-time data from a third-party API, meaning it will fail to update rates offline.
