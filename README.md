# Crypto & Scientific Utility Suite

## Target User
A crypto trader or student who needs quick currency conversions, unit conversions, and advanced mathematical calculations in a single lightweight web view.

## Problem Solved
Eliminates the friction of switching between multiple separate applications for price tracking, unit conversion, and math calculations during fast-paced workflows.

## Three Checks That Prove It Works
1. Live Price Fetching: The app successfully queries the public API and displays the current live Bitcoin price upon loading.
2. Instant Conversion: Entering a numeric value into the crypto amount or unit input fields dynamically calculates and updates the output.
3. Scientific Calculation: Selecting operator and function buttons correctly evaluates standard mathematical expressions on the display screen.

## Main Limitation
The live currency feature relies on a public third-party API, meaning rapid, consecutive page refreshes can occasionally hit rate limits and delay price updates.
